Fundamentals of Software Architecture: Appendix, Discussion Questions

Source: Mark Richards and Neal Ford, Fundamentals of Software Architecture, 2nd edition (O'Reilly, 2025), appendix. Previous: Fundamentals of Software Architecture 27: The Laws of Software Architecture, Revisited. Next: Fundamentals Of Software Architecture: contents.

Takeaways
  • The appendix lists review questions for each chapter, 1 to 27, with no answer key. Each chapter note in this digest holds the material that answers them.
  • Below, each chapter's questions are summarised as a topic map (what the questions probe), with a link to the note to re-read. The questions themselves stay in the book.
  • Use it as a self-test: for each bullet, answer aloud, then check the linked note.

Summary points

  • 27 chapter question sets, no answers: the notes are the answer key.
  • Heaviest question sets: the styles (chapters 9 to 18), each probing strengths, weaknesses, quanta and partitioning.
  • Repeated themes: trade-offs, partitioning, quanta, coupling, characteristics, and recording the why.
