The Kubernetes Book 0: Preface

Source: Nigel Poulton and Pushkar Joglekar, The Kubernetes Book, 3rd ed. (Packt, 2025), Preface. Next: The Kubernetes Book 1: Kubernetes Primer.

Takeaways
  • The book is revised every year, because a two-year-old Kubernetes book can be "dangerously out of date".
  • All app files and YAML live in the TKB GitHub repo; use its 2025 branch.
  • Windows users swap line-continuation backslashes for backticks (or join the command onto one line).
  • Kubernetes objects are capitalised (Pod, Service) to separate them from generic ideas (a cloud "load balancer" vs a Kubernetes LoadBalancer).

0.1 Yearly updates

  • The author reviews every word and concept each year and re-tests every example against current Kubernetes versions.
  • Reason given: a book left untouched for five years, or even two, could mislead readers because Kubernetes moves fast.

0.3 The sample app and GitHub repo

The repo holds every app file and YAML listing used in the book. Steps:

  1. Install git (search the web for instructions for your platform).
  2. Clone the repo (creates a TKB directory).
  3. Switch to the 2025 branch.
git clone https://github.com/nigelpoulton/TKB.git
cd TKB
git fetch origin
git checkout -b 2025 origin/2025

0.4 Windows users

  • Most hands-on commands run on Linux, Mac and Windows; the few exceptions are explained where they occur.
  • Whenever a command is split over several lines with backslashes, Windows users should either:
    • remove the backslash and run it on one line
    • replace each backslash with a backtick

0.5 Terminology and responsible language

  • Kubernetes objects such as Pods and Services get a capital first letter, so a Kubernetes LoadBalancer is distinguishable from a cloud load balancer.
  • The book follows the Inclusive Naming Initiative guidelines on responsible language.
