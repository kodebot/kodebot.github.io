Core Java 2: The Java Programming Environment

Source: Cay S. Horstmann, Core Java, Volume I: Fundamentals, 14th ed. (Pearson, 2025), ch. 2. Previous: Core Java 1: An Introduction to Java. Next: Core Java 3: Fundamental Programming Structures in Java.

Takeaways
  • Install a JDK for Java SE 25 (LTS) from any OpenJDK vendor; brand names (Temurin, Corretto, Zulu) do not matter to a programmer.
  • Check the install with javac --version; if the command is not found, the PATH is wrong.
  • Since recent Java versions, java Welcome.java compiles and runs a source file in one step; the older two-step javac then java is still better for programs you run repeatedly.
  • Use the command line to troubleshoot and to see what an IDE does behind your back, then work in an IDE (Eclipse, IntelliJ IDEA, NetBeans, Visual Studio Code).
  • JShell is a REPL for trying expressions without writing a class or a main method.

2.1 Installing the Java Development Kit

  • Once Oracle was the only source of an up-to-date JDK. Now Amazon, Azul, Microsoft, Red Hat and others all ship OpenJDK builds, each with its own licence and support terms.
  • The Eclipse Foundation provides free builds for Linux, macOS and Windows that work well for learning.

2.1.1 Downloading the JDK

  • Download from the Eclipse Foundation at https://adoptium.net, from Oracle at https://www.oracle.com/java/technologies/downloads, or from many other providers.
  • Pick the Java SE 25 (LTS) JDK.

Table 2.1, Java jargon seen on download sites:

Name Acronym Meaning and advice
Java Development Kit JDK Software for people who write Java programs. You want this.
Java Runtime Environment JRE Runs programs without development tools; only supported until Java 8. You do not want it.
Standard Edition SE The platform for desktops and simple servers. You want this.
OpenJDK none Free, open-source implementation of Java SE.
Hotspot none The just-in-time compiler from Oracle. If asked, choose this.
OpenJ9 none Another just-in-time compiler, from IBM.
GraalVM none An ahead-of-time compiler for fast-starting executables; does not support all Java features. Not for this book.
Long Term Support LTS Supported for several years, unlike six-month releases. Choose the latest LTS.
Eclipse none A foundation that distributes open-source software.
Temurin none Brand name of the OpenJDK build the Eclipse Foundation distributes.
Adoptium none The Eclipse project that provides that OpenJDK build and distribution support.

2.1.2 Setting up the JDK

  • On Windows or macOS run the installer and accept the defaults.
  • On Linux uncompress the .tar.gz somewhere (for example your home directory or /opt) and add its bin directory to the PATH.
    • The usual way is one line at the end of ~/.bashrc or ~/.bash_profile:
export PATH=/opt/jdk-25.0.4/bin:$PATH
  • Test it in a terminal:
$ javac --version
javac 25.0.4
  • If you instead see "javac: command not found" (or the Windows equivalent), re-check the install.
  • The book writes $JAVA_HOME for the install directory (use %JAVA_HOME% in a Windows terminal); you can set that environment variable or substitute the real path.

Table 2.2, sample install directories:

Platform Directory
Windows (Adoptium) C:\Program Files\Eclipse Adoptium\jdk-25.0.4.11-hotspot
Windows (Oracle OpenJDK) C:\Program Files\Java\jdk-25
macOS /Library/Java/JavaVirtualMachines/jdk-25.0.4_11.jdk/Contents/Home
Linux where you unpacked the archive, for example /opt/jdk-25.0.4
  • Windows gotcha with the Oracle installer: it adds C:\Program Files\Common Files\Oracle\Java\javapath to the PATH, and that folder holds only javac, javaw, java and jshell.
    • javaw is a Windows-only launcher that starts a program without a console window.
    • Other tools live in the JDK's bin directory: call them by full path (for example javadoc) or add bin to the PATH, for instance with setx (open a new terminal afterwards).
  • The Adoptium installer does not have this problem: it puts all JDK tools on the PATH.

2.1.3 Source files and documentation

  • Download the book's examples from https://horstmann.com/corejava as corejava.zip and unzip anywhere.
    • Two directories appear: corejava-bookcode and corejava-modulechapter.
  • The JDK ships the library source as $JAVA_HOME/lib/src.zip; unzip it to see how the API is implemented.
    • It covers the public libraries only. For compiler, virtual machine, native methods and private helpers, see https://openjdk.org.
  • API documentation for Java 25 is at https://docs.oracle.com/en/java/javase/25/docs/, with an offline download on the Oracle downloads page.
  • Browser tip: define a custom search engine for the API search page and bind it to a keyword such as @j, so that @j println in the address bar looks up println.
    • The book's example URL uses the Java 21 docs path (.../javase/21/docs/api/search.html?q=%s); swap in 25 for the current docs.

2.2 Using the command-line tools

  • The JDK has no built-in editor, menus or debugger, unlike Visual Studio; you type commands in a terminal.
  • Why bother:
    • it is an essential skill for troubleshooting a fresh install before adding an IDE
    • doing the steps yourself shows what an IDE does behind your back

Run a first program

  1. Open a terminal and go to corejava-bookcode.
  2. Run java Welcome.java and the greeting prints.
  • Older Java needed two steps: javac Welcome.java (the compiler writes Welcome.class) then java Welcome (launches the JVM on the class name, not a file name).
  • Compiling once and running often is more efficient, but for simple demos one command is enough.

Listing 2.1, Welcome.java (uses Java 25 features that shorten simple programs; for older Java use the previous edition's code at https://horstmann.com/corejava/corejava13.zip):

// Welcome.java
/**
 * This program displays a greeting for the reader.
 */
void main()
{
    String greeting = "Welcome to Core Java!";
    IO.println(greeting);
    IO.println("=".repeat(greeting.length()));
}
  • Notice there is no class declaration, no public static, no String[] args: Java 25's compact source files allow a top-level main method, and IO.println replaces System.out.println
    • Chapter 3 explains them.

Things that go wrong (troubleshooting checklist)

  • Case matters: type main, not Main or MAIN.
  • "Bad command or file name" or "javac: command not found": re-check the PATH.
  • "Cannot find the file Welcome.java": check the file really is in the current directory; on Linux check capitalisation.
  • Some Windows editors silently append .txt and Explorer hides it for "known file types".
    • Use the dir console command, not Explorer, to see the true name, and rename if needed.

A graphical program

  • Run java ImageViewer.java from corejava-bookcode, choose File, Open, pick an image (samples are in images), and close the window or use File, Exit.
  • Listing 2.2, ImageViewer.java, is a much longer program but still short for what it does compared with C or C++.
    • It starts with import module java.desktop;, a Java 25 module import that brings in all packages of a module at once.
    • main calls EventQueue.invokeLater with a lambda that builds an ImageViewerFrame and shows it.
    • ImageViewerFrame extends JFrame (300 by 400 pixels), shows an image in a JLabel, uses a JFileChooser starting in the images directory, and has a menu bar with File, Open and Exit.
    • The Open action (a lambda with an unnamed _ parameter) loads the chosen file into an ImageIcon; Exit calls System.exit(0).
    • Desktop GUIs are now rare; details are in Volume II, chapter 10.

2.3 Using an integrated development environment

  • Command-line skills are for troubleshooting
    • day to day, use an IDE. Excellent free choices: Eclipse, IntelliJ IDEA, NetBeans, Visual Studio Code. The book demonstrates Eclipse, but any works.
  • Download Eclipse from https://eclipse.org/downloads for Linux, macOS or Windows and choose Eclipse IDE for Java Developers.

Loading the sample code in Eclipse:

  1. File, New, Project, then choose Java Project in the wizard.
  2. Click Next, uncheck "Use default location", Browse to the corejava-bookcode directory.
  3. Uncheck "Create module-info.java file", then Finish.
  4. Expand the project tree to find Welcome.java in the default package and double-click it.
  5. Right-click the file, choose Run, Run As, Java Application; output shows in the console pane.

2.4 JShell

  • JShell is a read-evaluate-print loop (REPL): you type an expression, it evaluates and prints it, then waits. Much faster to experiment with than a full IDE project.
  • Start it by typing jshell in a terminal. It greets you with its version and a jshell> prompt.

jshell> "Core Java".length()
$1 ==> 9

jshell> 5 * $1 - 3
$2 ==> 42

jshell> var answer = 6 * 7
answer ==> 42
  • You do not type IO.println: JShell prints the value of every expression.
  • $1 names the result so it can be reused; give a variable a better name with var.
  • Tab completion: type Math. then Tab twice to list every method of Math; type l and Tab to complete to log (listing log(, log10(, log1p().
    • Then Math.log10(0.001) returns -3.0.
  • History: press the up arrow to recall a line, edit with the left and right arrows, and press Enter (for example change 0.001 to 1000 to get 3.0).
  • Leave with /exit.
  • Benefit: you can learn the language and library without launching a heavy IDE or writing a program with a main method.

Summary points

  • Install a Java SE 25 LTS JDK, test with javac --version, and fix the PATH if needed.
  • java File.java runs a source file directly; javac plus java is the two-step form.
  • Learn the command line for troubleshooting, then use an IDE.
  • Use JShell to experiment quickly.
Terms to carry forward
  • JDK, JRE: development kit versus runtime-only package (JRE obsolete after Java 8).
  • OpenJDK: the free, open-source implementation of Java SE.
  • Hotspot, OpenJ9: just-in-time compilers; GraalVM: ahead-of-time compiler.
  • LTS: long-term-support release.
  • $JAVA_HOME, PATH: install directory and the search path for commands.
  • javac, java, jshell, javaw: compiler, launcher, REPL, console-less launcher on Windows.
  • src.zip: the library source shipped in the JDK.
  • REPL: read-evaluate-print loop.
  • Module import: import module <name>; (Java 25).
